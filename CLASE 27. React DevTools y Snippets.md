## React DevTools

Para una mejor y más amplia experiencia se recomienda la instalación dentro de nuestro ***browser*** de la ***extensión*** llamada:

	React Developer Tools

***Nota:*** Esta herramienta es util para poder inspeccionar nuestra ***aplicación*** y ***proyecto*** en desarrollo.

Tales como:

	- Virtual-DOM de React.
	- Componentes
		- Props
		- States
		- hooks

Datos útiles para desarrolladores.
